summary: "Database Manager, signed automatic updates, and verified command-line installers."
added:
  - "Database Manager for MySQL and PostgreSQL through the existing SSH connection."
  - "Database connection profiles, loopback SSH tunnels, and OS-keychain credentials."
  - "Database explorer, schema structure editor, paginated row browser, and transactional row editing."
  - "SQL workspace with dialect highlighting, query tabs, cancellation, result export, and redacted history."
  - "CSV, SQL dump, backup, and restore workflows with progress, cancellation, and verification."
  - "Users, roles, grants, session monitoring, health indicators, and an ER diagram."
  - "Signed automatic update checks, in-app installation, and relaunch."
  - "Verified install.sh and install.ps1 command-line installers."
fixed:
  - "Terminal copy and paste now use the native desktop clipboard."
  - "Database security hardening for read-only enforcement, SQL construction, dump credentials, and profile deletion."
  - "Host-key trust and database metadata fixes found during MVP acceptance."
knownIssues:
  - "Windows and macOS builds are unsigned. SmartScreen or Gatekeeper may ask for confirmation."
  - "DEB and RPM installs do not self-update; the app links to the release package instead."
  - "MySQL database rename is not supported."
  - "v0.1.0 installs cannot self-update because they predate the updater."

ServerDesk 0.1.1 adds the Database Manager and makes future releases installable from inside
the desktop app. Existing v0.1.0 installations need one manual upgrade before automatic updates
become available.
